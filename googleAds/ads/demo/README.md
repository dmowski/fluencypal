# Demo Demand Gen assets

Creative pack for **Fluency - International professionals (demand gen) 2** (`24365782522`). Final URL: `https://app.fluencypal.com/demo`. Poland only, people physically there, English.

The running record of this test is `history/experiments.md`.

## Why this set

14–15 Oct the campaign spent 181.93 PLN for 83 clicks and 0 conversions. The only conversion Google counts on this account for that campaign is **Submit lead form**, which fires when Stripe checkout starts. The previous lines promised “no account or card,” and the page then sent people to the practice quiz. That path does not start checkout.

The page now matches these lines: 3 minutes free, then one more hour with Marin for $6. **Continue for $6** opens `/practice`, where a signed-out person can sign in with email.
