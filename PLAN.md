## UI and Functionality

### Rooms

When user open Voice chat feature they should see list of rooms.
For example General, Politics, Cooking, TV-shows, YouTube channels

#### Rooms. Full view

When user open the room, they will see name of room on title with settings icon (Looks like "more" icon).
On settings, we have tabs:
Settings (available if admin),
Notification: ability to turn notification on, off, set sleeping hours.
Members: List of members (avatar, username, description, last online)

Then in room, user see list of messages and form of creation a new message.

#### Rooms. Creation

When someone want's to create a room, show that form:
title,
subtitle,
Safety section:
Info text: we want to make sure everyone is comfortable, so we will review each jointers

- Review members before joining. Options: Approve by all members, Approve by Alex only
- What user must describe about yourself before jointing. with predefined text like "Please tells use where are you from. What do you like in that topic." something generic, but provoking user to record 3 minutes speech. | Markdown
- is room is public (Will be shown on landing pages. Will lead more visitors)
- rules | Markdown
- What we discuss (Content that should relax user and make it easy to join) | Markdown

* rules,What we discuss and describe about yourself should be rich text editors
